PROJECT OVERVIEW

코드를 전부 읽지 않아도 됩니다. 프로그램의 큰 그림부터 보고, 궁금한 기능을 클릭해서 함수와 실제 코드까지 내려가 보세요.

🔒 이 화면은 오프라인 탐색용입니다. 코드를 변경하지 않습니다.

실제 수정은 AI에게 요청하고, 변경 계획을 승인한 뒤 진행하세요.

01 · 큰 그림

프로그램은 어떻게 구성되어 있나요?

파일의 역할과 코드 사이의 연결을 먼저 이해하세요.

프로그램 시작 흐름

탐지된 시작 함수의 정적 호출 관계입니다. 실제 실행 순서와 다를 수 있습니다.

호출 후보 시각화
각 상자를 클릭하면 함수 설명과 실제 코드 위치가 열립니다.

파일과 모듈

먼저 역할을 보고, 궁금한 파일을 클릭하세요.

02 · 동작 추적

어떤 기능이 궁금하세요?

주요 진입점·공개 함수 등을 자동으로 탐지한 목록입니다. 실제 기능 명칭은 코드에서 추가 확인하세요.

화살표는 코드에서 관찰한 호출 후보이며 비동기·동적 호출은 누락될 수 있습니다.
03 · 원하는 만큼 자세히

함수를 검색하고 깊게 이해하기

함수를 선택하면 역할, 입력과 관련된 코드, 호출 관계, 위치를 볼 수 있습니다.

04 · 안전한 변경 준비

어느 부분을 고치고 싶나요?

변경할 함수를 선택하면 영향받는 다른 함수를 추적하고, AI에게 전달할 수정 요청을 만들 수 있습니다.

왼쪽 목록에서 기능 또는 함수를 선택하세요.
왼쪽 방향으로 펼쳐지는 연결은 이 함수를 호출할 수 있는 상위 함수 후보입니다.
HTML은 읽기 전용입니다. AI가 실제 소스를 다시 확인하고 변경 계획을 제안한 뒤, 승인받아 수정하도록 요청합니다.
로컬에서 열리는 단일 HTML · 외부 서버·라이브러리·네트워크 연결 없음 · 정적 분석 결과는 실행 검증이 아님
